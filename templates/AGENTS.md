# AGENTS.md

你在这台机器上替 **{{OWNER}}** 干一件具体的事。你会自己判断，这里只讲三件事：**去哪、做什么、怎么交**。

> 这一页是入口，不是说明书。写长了没人读，写虚了会猜。目标是：一个刚醒来的 agent 读完这一页就能开工。

## 三步

1. **同步** —— 拉仓库。先试免密，不通再上 token；token 存工作区固定位置（`.env.local`，`600`，已 gitignore），**不要放 `/tmp`**，也不要写进 remote URL 后不摘掉。
2. **看** —— `tasks/*/` 里找 `owner` 指向本机的卡；`entries/` 里已有同 task-id 的 `done` 就跳过。
3. **做** —— 按卡上的「目标」「范围」做。**范围之外的一律不做**，发现了记下来交回去。

**没有指向你的卡 → 静默退出。** 不用报告，不用问一句「需要我做什么」。

## 交作业

做完写一条 entry，四个字段缺一不可：

```
- task: <task-id>
- status: done | blocked
- 正文: 推到哪一步 / 结论 / 卡点
- 产物: <路径或 URL，可机器检查的那种>
```

正文先说结论，再说过程。三行以内。写不进去说明没做完。

## 卡住了

三条通道，选一条，**不要选第四条「猜」**：

| 情况 | 怎么做 |
|---|---|
| 卡有歧义、要求互相矛盾、缺关键信息 | `status: blocked`，正文一行 `need: <谁> <要什么>`，然后停 |
| 按卡做完了，但发现更好的做法 | 按卡交，正文加一句「另外发现 X」。**不自己扩大范围** |
| 发现别的问题（bug、不一致、值得做的事） | 开 issue 说清楚，不动代码 |

`blocked` 不是失败，是有效结果。**别猜，也别用看起来合理的内容填空。**

## 不做什么

- 不改与这张卡无关的文件。
- 不装新依赖（除非卡上写了允许）。
- 不为了「跑通」去放宽验收条件——先按原样跑，跑不过就 blocked。
- 不把密钥、token、内网地址写进任何会被提交的文件。

## 自检（交之前）

```bash
./scripts/preflight.sh    # 环境摸一遍：版本、端口、依赖、数据目录
```

跑不过就别交。跑过了把输出贴进 entry 正文的最后一行——下一个人能直接用。
