# PITFALLS · 静默失败台账

> **收录标准只有一条：不报错，但结果是错的。**
>
> 会报错的不记——报错自己会说话，stack trace 里就写着。这里记的是那些「没声音不等于没跑」的事：依赖静默缺省、包管理器静默丢弃、宿主静默不加载、域名静默轮换。
>
> 一条二十字起，当场记。判断标准：**如果下一个人不写它会再撞一遍，就记。**
>
> 依据：对显式报错的标记率约 91%，对「格式对、值错了」只有 59%。差的这三十多个点，就是这份台账存在的位置。
>
> 分类轴（比时间序有用——时间序只答「最近踩了什么」，分类答「哪一类还没设防」）：
> `环境怪癖` / `设计假设错配` / `错误被吞` / `连锁幻觉` / `操作遗漏`

---

## <一句话症状，用你当时看到的现象原话>

**触发**：什么条件下会踩到（平台 / 版本 / 某个可选依赖缺失）。

**根因**：为什么它不报错。这一栏是重点——报错的东西不需要根因分析，不报错才需要。

**为什么没早发现（检测缺口）**：它静默了多久、最后是谁/什么发现的。这一栏直接逼出「该加什么检查」——比写「兜底」有产出。没有它，同一个坑会以另一个形式再出现一次。

**验证**：一条命令，能把「现在是坏的」和「现在是好的」区分开。

```bash
<command>    # 坏: <输出>    好: <输出>
```

**兜底**：现在代码里怎么防的（启动前拦截 / 校验 / 文档警告）。没防就写「没防，只能靠这条」。

## 样例（填第一条时删掉）

### 出声是噪声 / 电流声，但服务一切正常

> 类别：`错误被吞`

**触发**：调本地推理引擎，模型主权重在，但声码器权重（`speech_tokenizer/model.safetensors`）缺失或不完整。常见于手动下载中断、或只下了主体没下配套。

**根因**：推理库找不到声码器时**不抛错**，直接初始化成随机权重。于是整条链路「成功」返回音频——只是内容是噪声。日志里没有任何异常，`/health` 也是 ok。

**验证**：

```bash
ls -lh models/*/speech_tokenizer/model.safetensors   # 好: 约 651M；坏: 不存在或明显偏小
```

**兜底**：Node 侧与 Python 侧启动前都校验文件大小，不达标直接拒启。

---

### 装完了，面板/命令却不存在

> 类别：`错误被吞`（发布链路的 warning 被淹）

**触发**：包管理器在发布时处理 `bin` 字段，路径带 `./` 前缀会被判非法并**静默移除**。本地 `npm link` 或直接跑源码都正常，只有装了发布版的人受影响。

**根因**：校验发生在发布链路里，warning 级别，被后续输出淹没。发包的人看不到，装包的人以为装好了。

**验证**：

```bash
npx <pkg> --version        # 好: 打印版本；坏: command not found
tar -tzf <pkg>.tgz | grep bin/   # 看好包里的 bin 路径长什么样
```

**兜底**：`bin` 路径不写 `./` 前缀；发版后必跑一次「装完调一次」的冒烟。
